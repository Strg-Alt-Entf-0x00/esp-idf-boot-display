ESP-IDF Boot Display Studio User Guide

1. Visual Canvas & Magnetic Snapping

Drag and drop elements directly on the simulated 240x240 GC9A01 circular display. Elements are strictly clamped within the circular perimeter (R ≤ 96px) so they can never get lost off-screen. Moving an element near center (120, 120) within ±5px activates cyan guideline crosshairs and magnetically snaps it into place. Right-click any element on the display to center or hide it.

2. Contextual Element Inspector

Selecting an element in the layout or clicking it on the screen opens its properties. Positions (X, Y) and Scale feature synchronized range sliders and precise pixel spinboxes. The concentric Outer Progress Ring automatically hides irrelevant position controls and exposes direct Ring Radius (80–116px) and style options (48 Dots, Continuous Arc, Dashed Arc). Wordmark supports straight, bottom arc, and top arc text projection.

3. Multi-Color Elements & 16-Bit RGB565 Engine

Multi-color elements like the Animated Pixel Mascot offer separate controls for Body Fill and Eyes & Accent. Changing any color in the Inspector instantly updates the preview, synchronizes with the Kconfig defaults in the Colors tab, and calculates exact 16-bit RGB565 hex values (0x0000 black, 0x073F vibrant cyan, 0xFFFF white).

4. 32x32 Pixel Sprite Editor & Brand Logo Import

Draw custom pixel icons directly in your browser using the Pen, Eraser, and Clear icon tools. Alternatively, drag and drop any image (PNG, JPG, SVG) onto the dropzone for auto-binarization into an ultra-fast 1-bit monochrome C bitmap.

5. Web Serial Live Sync & ESP32 Hardware Console

Pair your ESP32-P4 development board over USB-C at 115200 baud via the top header Plug icon. Real-time telemetry (Init latency, Frame render time, LP firmware state) is displayed directly in the titlebar. Use the icon buttons under the display for instant hardware control (Loop, Single Cycle, Event Mode, Restart LP, Trigger Handoff, and Telemetry Query). Toggle the docked bottom Terminal Drawer anytime to send direct serial commands.

6. Production C-Header Export

The Export tab generates a complete, clean boot_logo_custom.h with pre-configured Kconfig macros, 5x7 font tables, and 1-bit bitmap masks ready to compile directly into your ESP-IDF project.
