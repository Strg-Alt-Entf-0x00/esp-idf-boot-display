Boot Display Studio · Reference

Architecture Overview: The ESP-IDF Boot Display driver delivers instant-on visual feedback using the autonomous LP-Core (ULP RISC-V @ 40MHz) over LP-SPI, switching seamlessly to HP-Core DMA SPI without bus collision.

Universal Composer: Compose circular boot displays using dynamic stacked elements: Progress Rings, Circular Typography, Pixel Mascots, and 1-bit custom imported Bitmaps.

Firmware Commands:

info — Query display driver statistics, frame timings, and init durations

state — Read current boot animation state

handoff — Release display bus from LP-Core to HP-Core

restart — Re-trigger autonomous LP-Core boot sequence

progress <0..100> — Report boot completion progress

mode <0..3> — Set boot display mode (Continuous, Static, Single-Cycle, Event-Driven)
